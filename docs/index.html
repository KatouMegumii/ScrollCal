Why ScrollCal

够用就好，不做多余的事。

没有账号、没有云同步、没有日程权限，也没有 Dock 图标。

连续滚动

滚轮或触控板一路滚下去，顶部年月跟着最新位置自动更新。

一屏一个月

视口高度正好是一个月的 6 行，滚动边界清晰，一屏一个整月。

滚动倍率

点右上角 1.0× 展开滑块，0.2× – 2.0× 按 0.1× 调，鼠标和触控板各调各的手感。

农历 · 节气 · 节日

优先级：公历节日 → 农历节日 → 除夕 → 节气 → 农历初一（显示月名）→ 农历日。

非本月灰掉

前后补位的日期保留显示并整格灰度化，跨月看几天不用来回翻。

跟随系统

深浅色、系统语言、一周起始日都自动适配（默认周一）。

键盘友好

⌘T 回到今天，⌘Q 退出，▲▼ 精确翻月。

原生且轻

菜单栏 App，无 Dock 图标；开机自启用系统原生 SMAppService。

How it works

三步，就这些。

#1

点一下菜单栏图标

弹出日历面板，并自动定位到今天所在的月份；左上角那格显示的就是今天的农历（例如「八月初八」）。

#2

滚轮 / 触控板上下滚

连续翻月，顶部年月与面板同步变化；觉得快了慢了，点 1.0× 拉一下倍率滑块。

#3

要精确就点 ▲▼

一次翻一整月；点左上角农历日期或按 ⌘T 回到今天；⌘Q 退出。

Install

装上去，三步。

  1. 从 Releases 下载 ScrollCal-x.y.dmg（或 .zip）。需要 macOS 14 或更高。
  2. 打开 DMG，把 ScrollCal.app 拖进「应用程序」。
  3. 首次打开前去掉隔离标记，然后打开它 —— 菜单栏就会出现 📅 图标，点它即弹出日历。
为什么需要这一步：项目没有 Apple 开发者签名与公证，macOS 首次会拦截未识别的开发者。 两种放行方式：在「访达」里右键点 App → 打开 → 再点「打开」；或者终端执行一次 xattr -dr com.apple.quarantine /Applications/ScrollCal.app。
Build from source

只需要 Command Line Tools，不用完整 Xcode。

git clone https://github.com/KatouMegumii/ScrollCal.git
cd ScrollCal
./build.sh      # 编译并打包到 build/ScrollCal.app
./install.sh    # 可选：装到 /Applications 并重启
仓库里的工具用途
Tools/CalendarDump命令行打印某月网格，校验农历 / 节气 / 节日：./build/caldump 2026 10
Tools/Preview离屏把面板渲染成 PNG，改样式时不用点菜单栏：./build/preview out.png dark 2026 10
Tools/InteractionTest开真实窗口 + 合成鼠标事件点按钮的自检脚本，验证点击命中与「定位今日」
Tools/make-icon.sh生成 App 图标（iconset → icns）
农历和节气是怎么算的：农历用 Foundation 内置的 Chinese calendar 换算（含闰月判定）； 二十四节气是自实现的 Meeus《Astronomical Algorithms》低精度太阳视黄经求解（精度约 0.01°）， 离线计算、不查表、不联网；节日由公历固定日 + 按星期推算（母亲节 / 父亲节 / 感恩节）+ 农历节日 + 除夕组成。
